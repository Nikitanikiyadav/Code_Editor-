# CodeArena

A real-time collaborative code editor. Create rooms, invite teammates,
and code together live.

## Tech Stack
- Frontend: React, Vite, Monaco Editor, Axios, React Router
- Backend: Django, Django REST Framework, Django Channels (ASGI)
- Real-time sync: Yjs (CRDT) over WebSockets
- Database: PostgreSQL | Message layer: Redis
